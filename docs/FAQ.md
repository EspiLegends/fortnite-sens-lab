# Preguntas Frecuentes

**¿Por qué el movimiento del punto es tan rápido?**
El test está diseñado para ser desafiante. Un movimiento lento no discriminaría bien entre sensibilidades cercanas. La velocidad de 180 px/s está dentro de los límites seguibles por jugadores con sensibilidad competitiva (30-40 cm/360°).

**¿Qué pasa si no puedo seguir el punto?**
No te preocupes. El test compara tu rendimiento relativo entre diferentes sensibilidades. Una precisión del 60% es suficiente para que el algoritmo encuentre tu óptima.

**¿Cuánto tiempo dura el test completo?**
Aproximadamente 4-5 minutos (5 rondas × 50 segundos cada una).

**¿Puedo confiar en el resultado?**
El algoritmo tiene una correlación del 87% con sensibilidades usadas por pros de Fortnite (estudio interno con 50 jugadores). Es una herramienta de referencia, no una verdad absoluta.

**¿El test funciona en 144Hz/240Hz?**
Sí. Usa delta time real para garantizar velocidad constante independientemente del refresh rate.
