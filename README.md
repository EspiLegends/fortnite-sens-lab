## ✨ Why Fortnite Sens Lab?

Most "sensitivity calculators" just convert numbers between games.  
**Sens Lab is different**: it's an **adaptive test** that measures *your* aim and finds your optimal sensitivity using a hybrid search algorithm (exploration + quadratic interpolation).

🧠 No more guessing. No more copy-pasting pro settings.  
🎯 Find **your** perfect sens — based on how *you* play.

---

## 🚀 Features

- 🎯 **Adaptive Test** — Tracking + Flicks phases with real physics (delta time).
- 🧮 **Smart Algorithm** — Hybrid search with quadratic interpolation across 5 rounds.
- 📊 **Player Profile** — Get classified as Tracker, Flicker, Hybrid, or Developing.
- ⚙️ **Complete Output** — X/Y sensitivity, ADS, Scope, eDPI, cm/360°.
- 💾 **Local Persistence** — Your results saved automatically (localStorage).
- 📱 **Responsive** — Works on desktop and mobile.
- 🔓 **Zero Dependencies** — Pure HTML/CSS/JS. No frameworks, no trackers.

---

## 🎮 How it works

1. Enter your **DPI**, weight preference, grip style and play style.
2. Complete **5 adaptive rounds** (tracking + flicks).
3. The algorithm **converges** to your optimal sensitivity.
4. **Copy the results** directly into your Fortnite settings.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Persistence**: localStorage
- **Hosting**: GitHub Pages
- **Algorithm**: Hybrid search + quadratic interpolation
- **Physics**: Real delta-time movement (framerate-independent)
